TEMPO Phase 38 – Direkter GitHub-Upload

1. Vorher auf dem iPhone ein frisches Backup in iCloud Drive sichern.
2. Das ZIP „TEMPO_Phase38_EINFACHER_GITHUB_UPLOAD.zip“ auf dem Mac entpacken.
3. Den darin enthaltenen Ordner „tempo-main“ öffnen.
4. Auf github.com/212Felix/tempo den Branch main auswählen.
5. Add file -> Upload files öffnen.
6. Sämtliche Dateien und Ordner INNERHALB von tempo-main auf die Uploadfläche ziehen.
   Wichtig: kein zusätzlicher tempo-main-Ordner im Repository!
7. Kontrollieren: src/App.tsx, src/phase38/strength-progression.ts,
   src/phase35/weekly-rhythm.ts, package.json und scripts/check-release-source.mjs.
8. Commit directly to main.
9. GitHub Actions: sowohl build als auch deploy müssen grün sein.
10. Erst danach die App neu laden, V0.38 und vorhandene persönliche Daten prüfen.

Nicht die installierte iPhone-PWA löschen. Weder FIT-Dateien noch iPhone-Backups in GitHub hochladen.

Vollständiger Vite-Build vorab offline nicht bestätigt; GitHub Actions entscheidet.
