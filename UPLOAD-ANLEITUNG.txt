TEMPO PHASE 37 · KORRIGIERTE VOLLSTÄNDIGE QUELLEN

Für den einfachen Upload nutze TEMPO_Phase37_EINFACHER_GITHUB_UPLOAD.zip.

1. Vorher ein neues TEMPO-Backup auf dem iPhone in iCloud Drive speichern.
2. Änderungs-ZIP entpacken, darin tempo-main öffnen.
3. Auf GitHub 212Felix/tempo den Branch main öffnen.
4. Add file -> Upload files.
5. ALLE INHALTE aus tempo-main per Drag & Drop auf die Uploadfläche ziehen
   (nicht den gesamten tempo-main-Ordner verschachtelt ablegen).
6. Prüfen, ob src/phase36/WorkoutDetail.tsx, src/phase37/intervals.ts,
   src/workouts/RunningPanel.tsx, src/workouts/StrengthPanel.tsx,
   src/planning/ReconciliationPanel.tsx und package.json aufgeführt werden.
7. Commit directly to main bestätigen.
8. Unter Actions zuerst den grünen Build abwarten. Erst dann
   die App in Safari und auf dem iPhone mit PHASE 37 prüfen.

NICHT die TEMPO-App deinstallieren, nicht Website-Daten löschen.
Die vorhandene lokale IndexedDB mit 20 Stores bleibt bestehen.
Der npm-/Vite-Produktions-Build konnte in der Erstellungsumgebung wegen
fehlender npm-Abhängigkeiten nicht vollständig ausgeführt werden.
GitHub Actions ist die abschließende Buildprüfung.
