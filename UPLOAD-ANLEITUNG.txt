TEMPO PHASE 35 – einfacher GitHub-Upload

1. Zuerst ein aktuelles iPhone-Backup in iCloud Drive speichern.
2. NUR TEMPO_Phase35_EINFACHER_GITHUB_UPLOAD.zip herunterladen und entpacken.
3. Den enthaltenen Ordner tempo-main öffnen (Cmd+Shift+. blendet versteckte Dateien ein).
4. Auf GitHub 212Felix/tempo, Branch main, Add file > Upload files öffnen.
5. ALLE INHALTE INNERHALB von tempo-main auf GitHub ziehen; nicht den übergeordneten Ordner.
6. Vor dem Commit prüfen, dass src/App.tsx, src/phase35/weekly-rhythm.ts, src/workouts/StrengthPanel.tsx und package.json enthalten sind.
7. Commit directly to main. Auf main muss src/App.tsx danach PHASE 35 enthalten.
8. GitHub Actions build+deploy müssen grün werden. Dann Mac und iPhone prüfen.

WICHTIG: Nicht die installierte iPhone-App löschen oder Website-Daten zurücksetzen. Niemals Backups/GPS/FIT in GitHub hochladen.
